# Mend branding

| File | Use |
|---|---|
| `mend-icon.svg` | App icon (48 px and up) |
| `mend-icon-small.svg` | App icon for 16 to 32 px: thicker line, no glow |
| `mend-logo.svg` / `mend-logo-dark.svg` | Icon and wordmark, for dark / light backgrounds |
| `mend-wordmark.svg` / `mend-wordmark-dark.svg` | Wordmark alone |
| `png/` | Icon rendered at 16 to 1024 px |

The icon is a waveform that is clipped and clicky on the left (orange,
damaged) and clean on the right (teal, repaired), joined by the dot, which
also ends the wordmark: *mend.* Colours: teal `#40d6c4`, orange `#f2a65a`,
background `#262b35` to `#111317`.

Everything here is generated by `make_icon.py` and `make_logo.py`; run
`./build.sh` to rebuild all sizes, `app/resources/mend.ico`, `mend.icns`,
`mend.png` and the embedded header logo. The wordmark is set in DejaVu Sans
(converted to outlines; DejaVu fonts are under a permissive Bitstream Vera
derived licence).

The artwork is part of the project and shares its MIT licence.
